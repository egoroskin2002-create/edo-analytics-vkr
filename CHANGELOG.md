## [0.1.0] - 2026-10-28

### Added
- Добавлена конфигурация кластера ClickHouse в `clickhouse/cluster-config.xml`.
- Добавлены конфигурационные файлы макросов для четырёх узлов ClickHouse:
  - `clickhouse/macros-1-1.xml`
  - `clickhouse/macros-1-2.xml`
  - `clickhouse/macros-2-1.xml`
  - `clickhouse/macros-2-2.xml`
- Добавлен сервис `kafka-init` для автоматизированного создания топика Kafka.
- Добавлены healthcheck-проверки для узлов ClickHouse.
- Добавлены зависимости запуска ClickHouse от готовности Kafka.
- Добавлена настройка каталога логов Kafka.

### Changed
- Настройки подключения ClickHouse вынесены в переменные окружения `CH_USER` и `CH_PASSWORD`.
- Секретный ключ Superset вынесен в переменную окружения `SUPERSET_SECRET_KEY`.
- Создание топика Kafka перенесено в отдельный сервис `kafka-init`.
- Конфигурация Docker Compose дополнена настройками кластера и проверками готовности сервисов.

### Configuration
- Кластер ClickHouse `edo_cluster` настроен по схеме «2 шарда × 2 реплики».
- Для топика `edo-documents` задано начальное число партиций `1` и replication factor `1`.
- Добавлены конфигурационные файлы макросов для определения шарда и реплики каждого узла.

### Notes
- Коммит конфигурации: `1624525` (`feat: configure ClickHouse cluster and Kafka init`).
- Генератор событий на Python и полная сквозная проверка потока данных на момент этой записи ещё не завершены.
